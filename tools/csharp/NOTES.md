# C# (CSharpier 1.4.0) port notes

Target: byte-for-byte `csharpier format` 1.4.0 output with the default
options (printWidth 100, indent 4 spaces, end of line auto), checked with

    WORK=/work/out-cs bash bench/corpus/cmp.sh <fastfmt> cs
    WORK=/work/out-cs bash bench/corpus/cmp.sh <fastfmt> cs2

`cs2` is the `cs` corpus pre-formatted with odd options per directory
(printWidth 40 / 150, tabs, indent 2; see `mkcs2.sh`) and referenced with the
defaults, so every file needs real reformatting.

## Layout

| file | what |
| --- | --- |
| `src/csharp/kinds.ts` | Roslyn SyntaxKind numbers, syntax types and their slots (generated by `genkinds.py` from Roslyn's Syntax.xml) |
| `src/csharp/lexer.ts` | Roslyn's lexer: tokens, trivia, preprocessor directives evaluated against the symbols, disabled text, interpolated/raw strings split the way the parser rescans them |
| `src/csharp/tree.ts` | the struct-of-arrays syntax tree (kinds, slots, parents, first/last tokens) |
| `src/csharp/parser.ts`, `pdecl.ts`, `pstmt.ts`, `pexpr.ts` | Roslyn's LanguageParser, refusing where Roslyn reports a syntax error |
| `src/csharp/doc.ts` | CSharpier's Doc model, PropagateBreaks, DocFitter, DocPrinter, DocUtilities |
| `src/csharp/print.ts` | the printing context and the shared printers (Token trivia, ExtraNewLines, SeparatedSyntaxList, TrailingComma, Modifiers, AttributeLists, ConstraintClauses, OptionalBraces, CSharpierIgnore, ArgumentListLike, ArgumentListWithTrailingLambda, RightHandSide, MembersWithForcedLines, NamespaceLikePrinter, UsingDirectives) |
| `src/csharp/pnodes.ts` | Node.Print (the dispatcher) and the declaration and statement printers |
| `src/csharp/pexprs.ts` | expression, pattern, type and query printers, BinaryExpression |
| `src/csharp/pchain.ts` | InvocationExpression.PrintMemberChain |
| `src/csharp/psyms.ts` | PreprocessorSymbols.GetSets with BooleanExpressionParser |
| `src/csharp/run.ts` | the pipeline: generated-file checks, BOM, parse, auto-generated comment check, line ending, print, a reprint of the formatted code per symbol set |

## Tools

- `tools/dev/csharp.ts`: one file to stdout (exit 1 when refused; `FFDEBUG=1`
  says why, `FFDEBUG=1 FFCS_NOSYMS=1` skips the symbol-set reprints).
- `tools/csharp/devcmp.sh <driver> <corpus> [max] [skip]`: the dev driver
  over a corpus, one process per file, differing and refused files listed.
- `tools/csharp/testfiles.sh <driver>`: CSharpier's own formatting tests
  (`Src/CSharpier.Tests/FormattingTests/TestFiles/cs`).
- `tools/csharp/bench.ts`: formats files in one process, each in a region, for
  callgrind.
- `tools/csharp/parsedump.ts`, `lexdump.ts`: parser and lexer checks.
- `genkinds.py`, `fiximports.py`, `hoistimports.py`: kinds.ts generation and
  import upkeep (write code with K_/Y_/F_ names, then run hoist + fix).

## Ported

Everything in CSharpier's C# printer: all node printers, the member chain,
binary expressions, right hand sides, usings sorting (with an ICU-like
culture compare for InvariantCultureIgnoreCase), modifier sorting,
csharpier-ignore (node, range, members, lists, method with attributes),
directives and disabled text, regions, raw and verbatim strings (with
Roslyn's raw string dedent for ValueText), the preprocessor symbol sets and
reprints, generated and auto-generated file skipping, BOM, CRLF.

Details that matter for byte equality:

- `TrailingComma.Print` prints `SyntaxFactory.Token(CommaToken)`, whose
  elastic leading trivia consumes a pending `NextTriviaNeedsLine` even when
  the comma is then dropped.
- `field` is a FieldExpression (UnhandledNode: its full text, comments
  included, trimmed) in property accessors and property expression bodies.
- Group ids: CSharpier's `""` id is shared; all others are unique.
- `Token.PrintWithSuffix(token, Doc.Null)` still builds a Concat.
- PropagateBreaks, ContainsBreak and RemoveInitialDoubleHardLine follow the
  C# object graph exactly: shared docs are shared indices, concats are
  mutated in place.

## Known differences / not ported

- Options other than the defaults (useTabs, indentSize, printWidth, end of
  line); `.csharpierrc` / `.editorconfig` are not read.
- UTF-16 files are refused (CSharpier decodes them).
- A file CSharpier would crash on (a preprocessor condition its
  BooleanExpressionParser rejects, a too-deep tree) is refused.

CSharpier's own tests: 197 / 208 pass; the rest are the tab tests, the
auto-generated tests (which assume `--include-generated`), a UTF-16 file
and a BOM the test harness adds.

## Timings

13992 files, 164 MB, 4 cores:

| | 4 cores | 1 core (`taskset -c 0`, `-j 1`) |
| --- | --- | --- |
| csharpier 1.4.0 (`--no-cache`) | 40.7 s | 122.1 s |
| fastfmt (cmp.sh wall time) | 2.0 s | 6.6-7.0 s |

The machine is shared, so wall times vary by about 30%; callgrind on 200
corpus files went from 1.59G to 1.34G instructions with the buffer sizing,
the packed printer stack and the unchecked Doc and lexer accesses. The Doc
printer (PropagateBreaks, fits, print) is about a third of the work, parsing
another third, building the Docs the rest; nothing stands out any more.

csharpier's .NET start-up is about 0.43 s for one small file.
